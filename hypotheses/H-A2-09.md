# H-A2-09 — Which scope rule do KU-RO totals follow? (test on unseen documents only)

- **Logged:** 2026-11-06 (the merge commit is the timestamp of record)
- **Task:** A2 follow-up to the exploratory census (`experiments/A2/exploratory/README.md`)
- **Layer:** L0, integers. Fractions are reported only under a value set named at run time, as secondary.
- **Status:** pre-registered. **Test data: documents not in corpus-v0.1.**
- **Batch:** A2 registration batch 3 = {H-A2-06, H-A2-09}. Running count of A2 hypotheses registered: 5.

## Background
The exploratory census suggested three ways a KU-RO might choose its entries. All three come from corpus-v0.1 data that has already been seen, so they can only be tested on **documents nobody on the project has examined**.

| Rule | Entries summed by a KU-RO | Suggested by |
|---|---|---|
| **R0** (= S1 of H-A2-08) | unmarked entries since the previous marker (KU-RO, KI-RO, PO-TO-KU-RO) or the start of the side | the default |
| **R1 running total** | as R0, **plus the value of the previous KU-RO on the same side**, if there is one | HT 127b: 292 = 156 + 136 |
| **R2 section** | as R0, but a ruled line (lineara.xyz encodes it as "—", U+2014) also starts a new section | ZA 15b (ruling between heading and KU-RO) |

R1 and R2 can be combined (R12). Against R1, on already-seen data: HT 25b's second KU-RO (52) equals its own entries only, not those entries plus the earlier KU-RO (16).

## Data
- KU-RO occurrences in Linear A documents that are **not in corpus-v0.1** and not held out. Expected sources:
  - documents added in corpus-v1.0 (SigLA, Younger), listed by diffing document IDs against corpus-v0.1;
  - new publications.

  The held-out sceptre has no KU-RO, as far as is known.
- **Only clean rows count.** The total and every entry under any rule must be undamaged, both in the edition's marks and in a GORILA (or equivalent) check. The check is committed before any sum is computed, as in H-A2-08.
- **"Ruled line":** the U+2014 token in lineara.xyz. In other sources, the equivalent mark of a horizontal ruling.

## Test
For each clean KU-RO, compute whether the total equals the sum under R0, R1, R2 and R12. Count the exact matches per rule.

## Decision rule
- If fewer than 5 clean KU-RO occurrences exist in unseen data: **descriptive only**. Report per-row results and make no claim. This outcome is likely, since lineara.xyz already contains most published tablets.
- **Otherwise:**
  - R1 or R2 counts as **supported over R0** if it has at least 2 more exact matches than R0, **and** R0 is exact on no row where the rule fails.
  - Fewer than that: **no preference**.
  - R12 is reported but not tested separately.

## What I already know that could bias this
Every KU-RO in corpus-v0.1 has been summed (exploratory census, 2026-11-05), including HT 127b, HT 25b, ZA 15b and HT 118. That is why the test is restricted to unseen documents. In practice, corpus-v1.0 may add few or no new KU-RO tablets. If so, this hypothesis will end up descriptive only, and that outcome should be recorded rather than the rules being tested on seen data.
