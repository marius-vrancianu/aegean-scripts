# H-A2-07 — Fraction signs are written in a consistent order

- **Logged:** 2026-11-04 (the merge commit is the timestamp of record)
- **Task:** A2.9 precondition (plan v1.2). Test run after merge.
- **Layer:** L0 for the primary test (sign identities and positions only). Values are used in the secondary test only.
- **Status:** pre-registered
- **Batch:** A2 registration batch 1 = {H-A2-04, H-A2-07}. Running count of A2 hypotheses registered: 2.

## Why this matters
H-A2-06 (the held-out sceptre test, still to be registered) assumes that Minoan scribes wrote fraction signs in a fixed order, so that the order on the sceptre handle reveals relative values. This hypothesis tests that assumption on the training corpus first.

The primary test is **value-free** on purpose. "Descending order of value" may have been one of the six premises that Corazza et al. 2021 built their values from (to be verified against the PDF). If it was, testing order under their values would be circular.

## Hypothesis
Within a quantity, when two or more separately written fraction signs follow each other, each pair of distinct signs tends to appear in one fixed order, consistently across the corpus. That is, the pairwise orders are consistent with a single ranking of the signs. The alternative is free ordering.

## Data
- corpus-v0.1 @ fc87559. All quantities produced by `aegean.arithmetic.parse.parse_document`, held-out documents excluded.
- **Unit of analysis:** an adjacent pair (X, Y) of fraction signs within one quantity's fraction list, where X ≠ Y.
- Ligature codepoints that encode a sign combination in one character (U+10755 JE, U+10753 DD) are treated as single written units. They are **not** split into their parts.
- Pairs with an identical sign twice (e.g. D D written separately) are excluded, since they carry no order information. Their count is reported.
- **Primary analysis:** all such pairs, damaged and undamaged. **Secondary:** undamaged quantities only.

## Test (primary, value-free)
1. For each unordered sign pair {X, Y} observed adjacent at least once, count n(X→Y) and n(Y→X). The pair's majority order is the larger of the two; ties are counted as inconsistent.
2. **Statistic C** = (sum over pairs of the majority count) / (total number of adjacent distinct pairs). C = 1 means every pair always appears in the same order.
3. **Ranking check:** test whether the set of majority orders is acyclic, i.e. consistent with one total ranking of the signs. Report any cycles.
4. **Null:** within every quantity's fraction list, randomly permute the positions of the signs, keeping the multiset of signs in each quantity. Recompute C. Use 10,000 permutations with seed `20261104`. The p-value is the share of permutations with C ≥ the observed C.

## Test (secondary, uses values; reported, not decisive)
Using the Corazza et al. 2021 Table 8 values (verified against the PDF before the run), report the share of adjacent valued pairs in strictly descending value. Signs with no value in Table 8 (W, X, Y, L, Ω) are skipped, and the skipped count is reported. If verification shows that descending order was a Corazza premise, label this result "consistency check, not independent evidence".

## Known-script validation
None is available. Linear B uses these signs as units of measure, not as written fraction sequences. This limitation is accepted, and the result is interpreted as a statement about Linear A writing practice only.

## Decision rule
- If there are fewer than 15 adjacent distinct pairs in total: **inconclusive (insufficient data)**. Report the counts and stop. H-A2-06 is then recorded as untestable.
- **Supported:** C ≥ 0.90, the majority orders are acyclic, and p < 0.01.
- **Not supported:** C < 0.75, or p ≥ 0.05.
- **Inconclusive:** anything else.

**Consequence for H-A2-06:** it may be registered with "the observed order on the sceptre reveals relative value" only if H-A2-07 is supported.
